# Diclas Waste Oil Management — Brand Website

A modern, professional B2B website for Diclas Waste Oil Management, a Namibian waste oil management and marine environmental services company.

## Tech Stack

- **Framework:** Next.js 14 (App Router)
- **Styling:** Tailwind CSS
- **Font:** DM Sans (Google Fonts)
- **Language:** TypeScript

## Design

- **Aesthetic:** Premium industrial, corporate, professional
- **Colors:** Deep navy (#0F172A), charcoal (#1E293B), white, muted teal accent (#0D9488)
- **Typography:** Strong, clean sans-serif (DM Sans)
- **Layout:** Spacious, modern cards, subtle shadows, responsive

## Pages

- **Home** — Hero, trust strip, services overview, why choose us, projects preview, environmental responsibility, contact CTA
- **About** — Company overview, vision & mission, operational strengths, location & service area
- **Services** — 11 service offerings (ship repair, waste removal, tank cleaning, sewage, hazardous waste, etc.)
- **Projects** — Gallery of completed work with captions and categories
- **References** — Client references in card layout
- **Contact** — Address, phone, email, contact form, map section

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Deployment

Suitable for deployment on Vercel, Netlify, or any Node.js hosting. Configure environment variables as needed for contact form submissions (e.g. API integrations).

## Contact Form

The contact form is client-side only. Connect to your preferred backend (e.g. Formspree, SendGrid, custom API) for production use.
