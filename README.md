# Diclas Waste Oil Management — Brand Website

Professional brand website for **Diclas Waste Oil Management (Pty) Ltd**, a Namibian marine waste management and environmental services company based in Walvis Bay.

## Tech Stack

- **Framework:** Next.js 16 (App Router)
- **Styling:** Tailwind CSS v4
- **Language:** TypeScript
- **Icons:** Lucide React
- **Fonts:** Inter (via next/font/google)

## Pages

| Route | Description |
|-------|-------------|
| `/` | Homepage — Hero, trust strip, services grid, why choose us, projects preview, environmental section, CTA |
| `/about` | Company overview, mission/vision, operational strengths, service area |
| `/services` | All 11 services with detailed descriptions and capabilities |
| `/projects` | Project gallery with 12 case studies, categories, and scope details |
| `/references` | Client sectors, industry references, and testimonials |
| `/contact` | Contact form, contact info, and Google Maps embed |

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build

```bash
npm run build
npm start
```

## Brand Direction

- **Colors:** Deep navy (#0B1D3A), charcoal (#1E1E1E), white, muted teal (#0D7C6E)
- **Aesthetic:** Premium industrial, clean, spacious, professional
- **Typography:** Inter — strong, modern, highly readable
- **Tone:** Corporate, direct, operationally focused
